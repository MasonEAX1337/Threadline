# Inter

`inter-latin-variable.woff2` is the unmodified Latin, normal-style variable weight subset (100–900) from `@fontsource-variable/inter@5.3.0`, originally `files/inter-latin-wght-normal.woff2`.

- Typeface: Inter, by the Inter Project Authors — https://github.com/rsms/inter
- Distribution: https://www.npmjs.com/package/@fontsource-variable/inter/v/5.3.0
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

The file is committed and loaded with `next/font/local`. Builds and browser visits do not fetch fonts from Google, Fontsource, or another CDN. The app uses a system monospace stack for code and identifiers.
